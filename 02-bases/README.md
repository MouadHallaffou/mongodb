# Module 2 : Les bases de MongoDB

## Concepts clés

- Document : unité de données (format JSON)
- Collection : groupe de documents
- Base de données : ensemble de collections

## Types de données

- String, Number, Boolean, Array, Object, Date, etc.

## Opérations CRUD

- Create : ajouter un document
- Read : lire des documents
- Update : modifier un document
- Delete : supprimer un document
