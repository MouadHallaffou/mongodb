# Challenge : Installation et première base

1. Installez MongoDB sur votre machine ou créez un compte MongoDB Atlas.
2. Lancez MongoDB Compass et connectez-vous à votre serveur.
3. Créez une base de données nommée `testdb`.
4. Créez une collection `users` et insérez un document :
   ```json
   { "name": "Alice", "age": 25 }
   ```
5. Vérifiez que le document a bien été ajouté.
