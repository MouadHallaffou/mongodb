# Module 1 : Introduction à MongoDB

MongoDB est une base de données NoSQL orientée documents. Elle stocke les données sous forme de documents JSON.

## Objectifs

- Comprendre le concept NoSQL
- Installer MongoDB (local et cloud)
- Découvrir MongoDB Compass et le shell

## Installation

- [Guide officiel](https://www.mongodb.com/docs/manual/installation/)
- MongoDB Atlas pour le cloud

## Outils

- MongoDB Compass : interface graphique
- Mongo Shell : ligne de commande
